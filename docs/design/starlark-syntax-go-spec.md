# starlark-syntax-go: Automated Starlark Parser Distribution

## Overview

`starlark-syntax-go` is a standalone Go package providing Starlark parsing capabilities, automatically synced via Copybara with full history preservation.

**Repository**: `github.com/albertocavalcante/starlark-syntax-go`

## Goals

1. **Zero manual sync** - Copybara handles extraction and history preservation
2. **No custom tooling in repo** - Use existing tools (Copybara, GitHub Actions)
3. **Decouple from "build" association** - Starlark is a general-purpose language
4. **Proper attribution** - License files preserved automatically
5. **Future-proof** - Path to CST-first parser for advanced tooling

### Usage Examples

```go
// Parse MODULE.bazel
import "github.com/albertocavalcante/starlark-syntax-go/bazel"

content := []byte(`module(name = "my_module", version = "1.0.0")`)
file, err := bazel.Parse("MODULE.bazel", content)
for _, stmt := range file.Stmt {
    if call, ok := stmt.(*bazel.CallExpr); ok {
        fmt.Println("Function:", call.X.(*bazel.Ident).Name)
    }
}
```

```go
// Parse pure Starlark
import "github.com/albertocavalcante/starlark-syntax-go/starlark"

content := []byte(`def greet(name): return "Hello, " + name`)
file, err := starlark.Parse("example.star", content, 0)
```

### Workflow 1: Bazel Parser (from buildtools)

```python
# ==============================================================================
# infra/copybara/starlark-syntax-go/bazel.bara.sky
#
# Syncs the Starlark parser from bazelbuild/buildtools to starlark-syntax-go/bazel/
#
# COPYBARA REFERENCE DOCUMENTATION:
#   - Full Reference: https://github.com/google/copybara/blob/master/docs/reference.md
#   - Examples: https://github.com/google/copybara/blob/master/docs/examples.md
#
# UPSTREAM SOURCE:
#   - Repository: https://github.com/bazelbuild/buildtools
#   - Package: build/ (Starlark/BUILD file parser)
#   - License: Apache 2.0
# ==============================================================================

# ------------------------------------------------------------------------------
# authoring.pass_thru(default)
# Ref: https://github.com/google/copybara/blob/master/docs/reference.md#authoringpass_thru
#
# Preserves the original commit author from the source repository.
# Falls back to the 'default' author for squash commits or when author is unknown.
#
# Parameters:
#   default: string - Author in "Name <email>" format used as fallback
#
# Alternative modes:
#   - authoring.overwrite(default): Always use the default author
#   - authoring.allowed(default, allowlist): Only allow specific authors
# ------------------------------------------------------------------------------
defaultAuthor = authoring.pass_thru("Eukia[bot] <eukia[bot]@users.noreply.github.com>")

# ------------------------------------------------------------------------------
# core.workflow(...)
# Ref: https://github.com/google/copybara/blob/master/docs/reference.md#coreworkflow
#
# Defines a migration workflow from origin to destination with transformations.
#
# Key parameters:
#   name: string - Workflow name (used in CLI: copybara config.sky workflow_name)
#   origin: origin - Where to read code from (git.origin, folder.origin, etc.)
#   destination: destination - Where to write code to (git.destination, etc.)
#   origin_files: glob - Which files to include from origin
#   destination_files: glob - Which files in destination are managed by this workflow
#   mode: string - SQUASH, ITERATIVE, CHANGE_REQUEST, CHANGE_REQUEST_FROM_SOT
#   authoring: authoring_class - How to handle commit authors
#   transformations: list - Transformations to apply (move, replace, etc.)
# ------------------------------------------------------------------------------
core.workflow(
    name = "sync-bazel-parser",

    # --------------------------------------------------------------------------
    # git.origin(url, ref, ...)
    # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#gitorigin
    #
    # Defines a git repository as the source of files.
    #
    # Parameters:
    #   url: string - Git repository URL
    #   ref: string - Branch, tag, or commit to sync from (default: None = default branch)
    # --------------------------------------------------------------------------
    origin = git.origin(
        url = "https://github.com/bazelbuild/buildtools.git",
        ref = "master",
    ),

    # --------------------------------------------------------------------------
    # git.github_destination(url, push, ...)
    # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#gitgithub_destination
    #
    # Defines a GitHub repository as the destination.
    # Similar to git.destination() but with GitHub-specific features.
    #
    # Parameters:
    #   url: string - GitHub repository URL
    #   push: string - Branch to push to (default: 'master')
    # --------------------------------------------------------------------------
    destination = git.github_destination(
        url = "https://github.com/albertocavalcante/starlark-syntax-go.git",
        push = "main",
    ),

    # --------------------------------------------------------------------------
    # glob(include, exclude=[])
    # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#glob
    #
    # Creates a glob pattern to match files. Uses Java glob syntax.
    #
    # Parameters:
    #   include: list[string] - Patterns to include (supports **, *, ?)
    #   exclude: list[string] - Patterns to exclude (default: [])
    #
    # Pattern syntax:
    #   ** = matches any number of directories
    #   *  = matches any characters except /
    #   ?  = matches any single character
    #
    # Examples:
    #   glob(["**/*.go"]) = all .go files recursively
    #   glob(["foo/**"], exclude=["**/test/**"]) = foo/ except test/
    # --------------------------------------------------------------------------
    origin_files = glob(
        include = [
            "build/lex.go",        # Lexer
            "build/parse.y.go",    # Parser (yacc-generated)
            "build/syntax.go",     # AST node types
            "build/quote.go",      # String quoting utilities
            "build/walk.go",       # AST traversal
            "build/utils.go",      # Utility functions
            "labels/labels.go",    # Bazel label parsing
            "LICENSE",             # Apache 2.0 license
        ],
        exclude = [
            "**/*_test.go",        # Exclude all test files
        ],
    ),

    # --------------------------------------------------------------------------
    # destination_files: glob
    #
    # CRITICAL: This defines which files in the DESTINATION are "owned" by this
    # workflow. Files NOT matching this glob will NEVER be deleted by Copybara.
    #
    # Use this to:
    #   - Protect files managed by other workflows (e.g., doc.go from templates)
    #   - Protect files that only exist in destination (e.g., CI configs)
    #
    # WARNING: If two workflows have overlapping destination_files, they may
    # conflict and overwrite each other's changes!
    # --------------------------------------------------------------------------
    destination_files = glob(
        include = ["bazel/**"],
        exclude = ["bazel/doc.go"],  # Managed by templates workflow
    ),

    # --------------------------------------------------------------------------
    # mode: string
    # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#coreworkflow
    #
    # Controls how commits are migrated:
    #
    #   "SQUASH" - Combines all changes into a single commit
    #   "ITERATIVE" - Preserves individual commits (maintains history!)
    #   "CHANGE_REQUEST" - Creates a PR/CL for review
    #   "CHANGE_REQUEST_FROM_SOT" - CR from source-of-truth
    #
    # We use ITERATIVE to preserve the upstream commit history.
    # --------------------------------------------------------------------------
    mode = "ITERATIVE",

    authoring = defaultAuthor,

    # --------------------------------------------------------------------------
    # transformations: list[transformation]
    #
    # List of transformations applied IN ORDER to the files.
    # Each transformation modifies the working directory.
    #
    # Common transformations:
    #   core.move()    - Move/rename directories
    #   core.rename()  - Rename files by name pattern
    #   core.replace() - Find/replace in file contents
    #   core.remove()  - Remove files (rarely needed)
    #   metadata.*     - Modify commit metadata
    # --------------------------------------------------------------------------
    transformations = [
        # ======================================================================
        # STEP 1: Move directories
        # ======================================================================

        # ----------------------------------------------------------------------
        # core.move(before, after, paths=glob(["**"]), overwrite=False, regex_groups={})
        # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#coremove
        #
        # Moves files between directories. IMPORTANT: 'before' is treated as a
        # PREFIX, not an exact path!
        #
        # Parameters:
        #   before: string - Source path PREFIX (directory or file prefix)
        #   after: string - Destination path PREFIX
        #   paths: glob - Filter which files to move (relative to 'before')
        #   overwrite: bool - Overwrite existing files (default: False)
        #   regex_groups: dict - Named regex groups for dynamic paths
        #
        # How it works:
        #   core.move("build", "bazel") transforms:
        #     build/lex.go      → bazel/lex.go
        #     build/parse.y.go  → bazel/parse.y.go
        #     build/foo/bar.go  → bazel/foo/bar.go
        #
        # GOTCHA: core.move("build/lex.go", "bazel/lex.go") does NOT work as
        # expected! It treats "build/lex.go" as a prefix, not exact match.
        # Use core.rename() for file-level renaming instead.
        # ----------------------------------------------------------------------
        core.move("build", "bazel"),
        core.move("labels", "bazel/labels"),
        core.move("LICENSE", "bazel/LICENSE"),

        # ======================================================================
        # STEP 2: Rename files for clarity
        # ======================================================================

        # ----------------------------------------------------------------------
        # core.rename(before, after, paths=glob(["**"]), overwrite=False, suffix=False)
        # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#corerename
        #
        # Renames files by matching FILENAMES (not full paths).
        # This is a simplified version of core.move() for file renaming.
        #
        # Parameters:
        #   before: string - Filename or suffix to match
        #   after: string - Replacement filename or suffix
        #   paths: glob - Filter which directories to search
        #   overwrite: bool - Overwrite if destination exists
        #   suffix: bool - Match partial filename (for extensions)
        #
        # How it works:
        #   core.rename("syntax.go", "ast.go", paths=glob(["bazel/*.go"]))
        #     bazel/syntax.go → bazel/ast.go
        #     (other files unchanged)
        #
        # NOTE: Does NOT rename directories, only regular files.
        # ----------------------------------------------------------------------
        core.rename("parse.y.go", "parse.go", paths = glob(["bazel/*.go"])),
        core.rename("syntax.go", "ast.go", paths = glob(["bazel/*.go"])),
        core.rename("utils.go", "position.go", paths = glob(["bazel/*.go"])),

        # ======================================================================
        # STEP 3: Rewrite package declaration
        # ======================================================================

        # ----------------------------------------------------------------------
        # core.replace(before, after, regex_groups={}, paths=glob(["**"]),
        #              first_only=False, multiline=False, repeated_groups=False,
        #              ignore=[])
        # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#corereplace
        #
        # Find and replace text in file contents. Supports regex.
        #
        # Parameters:
        #   before: string - Text or regex pattern to find
        #   after: string - Replacement text (can use $1, $2 for groups)
        #   regex_groups: dict - Named regex groups {"name": "pattern"}
        #   paths: glob - Files to process
        #   first_only: bool - Only replace first occurrence per file
        #   multiline: bool - Enable multiline mode (^ and $ match line boundaries)
        #   repeated_groups: bool - Allow same group multiple times
        #   ignore: list[string] - Regex patterns to skip
        #
        # GOTCHA: Without regex_groups={}, 'before' is treated as LITERAL text.
        # To use regex features (^, $, *, etc.), you MUST pass regex_groups={}.
        #
        # Examples:
        #   # Literal replacement (no regex):
        #   core.replace(before="foo", after="bar")
        #
        #   # Regex replacement (note regex_groups={}):
        #   core.replace(before="^package build$", after="package bazel",
        #                regex_groups={}, multiline=True)
        #
        #   # With capture groups:
        #   core.replace(before="version = ${v}", after="VERSION = ${v}",
        #                regex_groups={"v": "[0-9.]+"})
        # ----------------------------------------------------------------------
        core.replace(
            before = "^package build$",  # Regex: start of line, literal, end of line
            after = "package bazel",
            regex_groups = {},           # REQUIRED to enable regex mode!
            multiline = True,            # Make ^ and $ match line boundaries
            paths = glob(["bazel/*.go"]),
        ),

        # ======================================================================
        # STEP 4: Rewrite import paths
        # ======================================================================

        # Include quotes in the pattern to avoid false matches in comments/strings
        core.replace(
            before = '"github.com/bazelbuild/buildtools/build"',
            after = '"github.com/albertocavalcante/starlark-syntax-go/bazel"',
            paths = glob(["**/*.go"]),
        ),
        core.replace(
            before = '"github.com/bazelbuild/buildtools/labels"',
            after = '"github.com/albertocavalcante/starlark-syntax-go/bazel/labels"',
            paths = glob(["**/*.go"]),
        ),

        # ======================================================================
        # STEP 5: Metadata transformations
        # ======================================================================

        # ----------------------------------------------------------------------
        # metadata.expose_label(name, ...)
        # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#metadataexpose_label
        #
        # Preserves Git trailers (Co-authored-by, Signed-off-by, etc.) from the
        # original commit message.
        #
        # Parameters:
        #   name: string - Label name to preserve (e.g., "Co-authored-by")
        # ----------------------------------------------------------------------
        metadata.expose_label("Co-authored-by"),
        metadata.expose_label("Signed-off-by"),

        # ----------------------------------------------------------------------
        # metadata.add_header(text, ...)
        # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#metadataadd_header
        #
        # Adds a header line to the commit message.
        # Useful for tracking where commits came from.
        #
        # Parameters:
        #   text: string - Header text to prepend to commit message
        # ----------------------------------------------------------------------
        metadata.add_header("Synced-From: bazelbuild/buildtools/build"),
    ],
)
```

### Workflow 2: Starlark Parser (from starlark-go)

```python
# ==============================================================================
# infra/copybara/starlark-syntax-go/starlark.bara.sky
#
# Syncs the Starlark parser from google/starlark-go to starlark-syntax-go/starlark/
#
# COPYBARA REFERENCE DOCUMENTATION:
#   - Full Reference: https://github.com/google/copybara/blob/master/docs/reference.md
#   - Examples: https://github.com/google/copybara/blob/master/docs/examples.md
#
# UPSTREAM SOURCE:
#   - Repository: https://github.com/google/starlark-go
#   - Package: syntax/ (Starlark parser and AST)
#   - License: BSD-3-Clause
# ==============================================================================

# See bazel.bara.sky for detailed documentation on authoring.pass_thru()
defaultAuthor = authoring.pass_thru("Eukia[bot] <eukia[bot]@users.noreply.github.com>")

core.workflow(
    name = "sync-starlark-parser",

    # See bazel.bara.sky for detailed documentation on git.origin()
    origin = git.origin(
        url = "https://github.com/google/starlark-go.git",
        ref = "master",
    ),

    # See bazel.bara.sky for detailed documentation on git.github_destination()
    destination = git.github_destination(
        url = "https://github.com/albertocavalcante/starlark-syntax-go.git",
        push = "main",
    ),

    # Files to sync from starlark-go/syntax/
    origin_files = glob(
        include = [
            "syntax/syntax.go",    # AST node types
            "syntax/parse.go",     # Recursive-descent parser
            "syntax/scan.go",      # Lexical scanner
            "syntax/quote.go",     # String quoting utilities
            "syntax/walk.go",      # AST traversal
            "syntax/options.go",   # Parse options
            "LICENSE",             # BSD-3-Clause license
        ],
        exclude = [
            "**/*_test.go",        # Exclude all test files
        ],
    ),

    # Manage starlark/ directory, but exclude doc.go (managed by templates)
    destination_files = glob(
        include = ["starlark/**"],
        exclude = ["starlark/doc.go"],
    ),

    # Preserve commit history
    mode = "ITERATIVE",

    authoring = defaultAuthor,

    transformations = [
        # STEP 1: Move syntax/ to starlark/
        # See bazel.bara.sky for detailed documentation on core.move()
        core.move("syntax", "starlark"),
        core.move("LICENSE", "starlark/LICENSE"),

        # STEP 2: Rename syntax.go to ast.go for clarity
        # See bazel.bara.sky for detailed documentation on core.rename()
        core.rename("syntax.go", "ast.go", paths = glob(["starlark/*.go"])),

        # STEP 3: Rewrite package declaration
        # See bazel.bara.sky for detailed documentation on core.replace()
        core.replace(
            before = "^package syntax$",
            after = "package starlark",
            regex_groups = {},       # Enable regex mode
            multiline = True,        # ^ and $ match line boundaries
            paths = glob(["starlark/*.go"]),
        ),

        # STEP 4: Rewrite imports (include quotes for precision)
        core.replace(
            before = '"go.starlark.net/syntax"',
            after = '"github.com/albertocavalcante/starlark-syntax-go/starlark"',
            paths = glob(["**/*.go"]),
        ),

        # STEP 5: Metadata
        metadata.expose_label("Co-authored-by"),
        metadata.expose_label("Signed-off-by"),
        metadata.add_header("Synced-From: google/starlark-go/syntax"),
    ],
)
```

### Workflow 3: Static Templates

```python
# ==============================================================================
# infra/copybara/starlark-syntax-go/templates.bara.sky
#
# Syncs static template files (go.mod, README, NOTICE, doc.go) to starlark-syntax-go
#
# COPYBARA REFERENCE DOCUMENTATION:
#   - Full Reference: https://github.com/google/copybara/blob/master/docs/reference.md
#   - folder.origin(): https://github.com/google/copybara/blob/master/docs/reference.md#folderorigin
#
# NOTE: This workflow uses folder.origin() to read from the local filesystem
# instead of cloning a git repo. This avoids self-referential clone issues when
# running from within the bazelbump repository.
#
# CLI USAGE:
#   java -jar copybara_deploy.jar migrate templates.bara.sky sync-templates \
#     --folder-origin-author="Eukia[bot] <eukia[bot]@users.noreply.github.com>" \
#     "infra/copybara/starlark-syntax-go/templates"
# ==============================================================================

defaultAuthor = authoring.pass_thru("Eukia[bot] <eukia[bot]@users.noreply.github.com>")

core.workflow(
    name = "sync-templates",

    # --------------------------------------------------------------------------
    # folder.origin()
    # Ref: https://github.com/google/copybara/blob/master/docs/reference.md#folderorigin
    #
    # Reads files from the local filesystem instead of a git repository.
    # The folder path is specified via CLI: --folder-origin PATH
    #
    # Use this when:
    #   - Syncing files from the same repo where Copybara config lives
    #   - Avoiding self-referential git clones
    #   - Testing with local files
    #
    # CLI flags:
    #   --folder-origin PATH: Directory to read from
    #   --folder-origin-author "Name <email>": Author for commits
    # --------------------------------------------------------------------------
    origin = folder.origin(),

    destination = git.github_destination(
        url = "https://github.com/albertocavalcante/starlark-syntax-go.git",
        push = "main",
    ),

    # Include all files from the folder origin
    origin_files = glob(["**"]),

    # Only manage these specific files in destination
    # This prevents this workflow from conflicting with bazel/starlark workflows
    destination_files = glob([
        "go.mod",
        "README.md",
        "NOTICE",
        "bazel/doc.go",
        "starlark/doc.go",
    ]),

    mode = "ITERATIVE",

    authoring = defaultAuthor,

    transformations = [
        # No file moves needed - templates/ structure matches destination
        metadata.add_header("Synced-From: bazelbump/infra/copybara/starlark-syntax-go/templates"),
    ],
)
```

**Alternative: Using git.origin() for templates**

If `folder.origin()` doesn't work in your environment, you can use `git.origin()`
with the bazelbump repository. However, this requires a separate job that checks
out bazelbump fresh (to avoid self-referential issues):

```python
# Alternative templates.bara.sky using git.origin

core.workflow(
    name = "sync-templates-git",

    origin = git.origin(

        "starlark/doc.go",
    ]),

    mode = "ITERATIVE",

    authoring = authoring.pass_thru("Eukia[bot] <eukia[bot]@users.noreply.github.com>"),
```

## Phase 3: CST-First Parser (Roslyn-Style)

### Vision

A Concrete Syntax Tree (CST) parser that preserves **all** source information:

- Lossless round-tripping
- Format-preserving refactoring
- IDE-quality error recovery
- Incremental parsing

### When to Build Custom Tooling

If we decide to build a CST parser, it should be:

1. **A proper Go module** in `tools/starlark-cst-parser/`
2. **Designed for spinoff** as `github.com/albertocavalcante/starlark-cst-go`
3. **Well-documented** with clear API
4. **Thoroughly tested** with fuzzing

### CST Design (Reference)

```go
// Token with trivia preservation
type Token struct {
    Kind           TokenKind
    Text           string
    Span           Span
    LeadingTrivia  []Trivia  // whitespace, comments before
    TrailingTrivia []Trivia  // whitespace, comments after
}

// Trivia represents non-semantic content
type Trivia struct {
    Kind TriviaKind  // Whitespace, Newline, Comment, Skipped
    Text string
    Span Span
}

// CST nodes preserve all tokens
type CallExprNode struct {
    Function   ExprNode
    OpenParen  Token      // (
    Arguments  []ArgNode  // with separating commas
    CloseParen Token      // )
}
```

This would only be built if:
- Existing parsers can't meet our needs
- We identify a clear problem space no existing tool solves
- We commit to maintaining it as a standalone tool

## Design Decisions & Gotchas

### Copybara API Gotchas

**Reference**: https://github.com/google/copybara/blob/master/docs/reference.md

1. **`core.move()` treats paths as PREFIXES, not exact matches**
   - Ref: https://github.com/google/copybara/blob/master/docs/reference.md#coremove
   - ❌ `core.move("build/syntax.go", "bazel/ast.go")` — won't work as expected
   - ✅ `core.move("build", "bazel")` then `core.rename("syntax.go", "ast.go")`
   - The `before` parameter is a path PREFIX, so `build/syntax.go` would match
     `build/syntax.go/anything`, not just the file itself

2. **`core.rename()` is for file renaming, `core.move()` is for directory restructuring**
   - Ref: https://github.com/google/copybara/blob/master/docs/reference.md#corerename
   - Use `core.rename(before, after, paths=glob([...]))` for renaming files
   - Use `core.move(before_dir, after_dir)` for moving directory contents
   - `core.rename()` matches FILENAMES only, not full paths

3. **`core.replace()` requires `regex_groups={}` for regex mode**
   - Ref: https://github.com/google/copybara/blob/master/docs/reference.md#corereplace
   - ❌ `core.replace(before="^package build$", ...)` — ^ and $ are literal!
   - ✅ `core.replace(before="^package build$", regex_groups={}, multiline=True, ...)`
   - Without `regex_groups={}`, the `before` string is treated as LITERAL text
   - Include quotes for import paths: `'"github.com/foo/bar"'` to avoid false matches

4. **`destination_files` protects files from deletion**
   - Files NOT matching `destination_files` are NEVER removed by Copybara
   - Use to protect files managed by other workflows
   - Example: `glob(["bazel/**"], exclude=["bazel/doc.go"])` protects doc.go

5. **Multiple workflows to same destination can conflict**
   - Each workflow tracks its own revision state
   - Ensure `destination_files` globs don't overlap between workflows
   - Or use a single workflow with multiple transformations

6. **`folder.origin()` for local files in CI**
   - Ref: https://github.com/google/copybara/blob/master/docs/reference.md#folderorigin
   - When syncing templates from the same repo, use `folder.origin()`
   - Pass `--folder-origin PATH` on the CLI to specify the directory
   - Avoids self-referential git clone issues

7. **ITERATIVE mode preserves commit history**
   - Each upstream commit becomes a separate destination commit
   - Use for maintaining attribution and history
   - SQUASH mode combines all changes into one commit

### GitHub Actions Gotchas

1. **`inputs` is null for scheduled runs**
   - ❌ `if: inputs.dry_run != true` — fails for cron triggers (inputs is null)
   - ✅ `if: ${{ inputs.dry_run != true }}` — expression syntax handles null correctly
   - In expression syntax, `null != true` evaluates to `true`

2. **Eukia bot token must specify all repos it needs access to**
   - List ALL repositories in the `repositories:` parameter
   - Example: `repositories: bazelbump,starlark-syntax-go`
   - Token only has access to explicitly listed repos

3. **Job dependencies with `needs:` and conditional `if:`**
   - If a job has `if:` that evaluates to false, dependent jobs are skipped
   - Use `always()` or `success()` in `if:` to control behavior
   - Example: `if: ${{ always() && needs.sync.result == 'success' }}`
