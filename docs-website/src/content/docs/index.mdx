## The Problem

Bazel dependency upgrades are painful:

- **Manual edits** to MODULE.bazel, WORKSPACE, and BUILD files
- **Breaking changes** that require coordinated updates across many files
- **No automation** - each upgrade is a bespoke, error-prone process
- **Hard to test** - dry-run modes are inconsistent or missing

## The Solution

bazelbump provides a recipe system for codifying upgrade patterns:

```starlark
recipe(
    name = "upgrade-rules-go",
    version = "1.0.0",
    description = "Upgrade rules_go to latest version",
    steps = [
        scan(
            id = "find-deps",
            name = "Find rules_go usage",
            impl = find_rules_go,
        ),
        edit(
            id = "update-version",
            name = "Update MODULE.bazel",
            depends_on = ["find-deps"],
            operations = update_ops,
        ),
    ],
)
```

## Quick Example

Format all Starlark files with buildifier:

```starlark
def format_ops(ctx):
    return [
        run_command(
            command = "buildifier -mode=fix .",
            description = "Format with buildifier",
            echo = True,
        ),
    ]

recipe(
    name = "format",
    version = "1.0.0",
    steps = [
        edit(
            id = "format",
            name = "Format files",
            operations = format_ops,
        ),
    ],
)
```

```bash
# Preview changes
bazelbump recipe run format.star --dry-run

# Apply changes
bazelbump recipe run format.star
```
